# 출장 신청

`file_trip` 으로 국내출장신청을 올린다. 기록된 출장은 `list_trips` 로 본다. 문서 공통 규칙은 `approval`.

## 출장목적은 사유다

무엇을 하러 가는지 쓴다. 출장지를 되풀이하지 않는다.

| 나쁨 | 좋음 |
|---|---|
| ○○군청 방문 | 실증 부지 인허가 협의 |
| 해외 출장 | 파트너십 실무 협의 |
| 행사 이름만 | 행사 부스 운영 |

- 도구가 출장지에서 온 말과 상투어(방문, 출장, 미팅, 회의, 참석, 업무 등)를 걷어 내고 남는 말이 없으면 거부한다. 하는 일(참석, 운영, 시연, 시험, 보고, 협의 등)이 없어도 거부한다.
- 거부되면 목적을 지어내지 말고 사람에게 묻는다. 통과했다고 좋은 사유가 되는 것은 아니다.
- 동행자와 상세 일정은 비고에 적는다.
- 출장여비는 목적을 구체적으로 남기고, 사진이나 녹취 같은 증빙을 함께 남긴다.

## 칸

| 칸 | 값 |
|---|---|
| 출장기간 | 시작일과 종료일 `YYYY-MM-DD`. 당일 출장은 둘이 같다 |
| 출장지 | 기관이나 장소 이름. 지역은 괄호에 적는다 |
| 교통편 | 고속철도(KTX/SRT), 시외버스, 항공편, 렌트카, 기타. 자차 항목이 없어 자차는 `기타` |
| 출장목적 | 위 규칙 |
| 비고 | 동행자, 일정 |

동행자 출장자 정보 표는 도구가 채우지 않는다.

## 제목

양식이 안내하는 형식이다: 출장일자/출장지/부서 코드/성함.

```
'26.03.02/테스트시청/rnd/홍길동
'26.03.02-03.03/테스트시청/rnd/홍길동
```

출장지는 괄호 속 지역을 뺀 이름을 쓴다. 출장지가 길면 `titlePlace` 로 제목에 쓸 이름을 준다. 부서 코드는 조직도의 코드를 그대로 쓴다.

## 중복 확인

- 내 기안 문서함과 부서 문서함의 출장 문서를 읽어 기간이 겹치고 출장지 말이 같으면 멈춘다. 같은 부서 사람이 먼저 올린 같은 출장도 잡힌다.
- 기간만 겹치는 문서는 참고로 보여 준다. 같은 날 다른 출장이 실제로 있다.
- **다른 부서 사람이 올린 같은 출장은 보이지 않는다.** 사람에게 확인한다.
- 겹치는 문서가 다른 출장이라고 사람이 확인하면 `allowOverlap` 을 넣는다. 미리보기에 겹치는 문서가 그대로 보인다.
- 반려된 문서는 겹쳐도 막지 않는다.

## 결재선과 참조

- 회사 설정 `trip.approvers` 와 `trip.referers` 를 따른다. 한 편집기 세션 안에서 결재선과 참조자를 함께 넣는다.
- 양식 기본 결재선은 비우고 설정의 결재자만 순서대로 넣는다. 상신 전에 `타입 이름` 순서가 정확히 같은지, 참조자 이름이 정확히 같은지 다시 본다. 이름 일부만 같은 사람은 같은 사람으로 치지 않는다.
- 양식에 기본 참조자가 들어 있는데 설정에 없으면 멈춘다. 미리보기에 없던 사람에게 알림이 가면 안 된다. 그 사람이 참조에 들어가야 하면 관리자에게 회사 설정 `trip.referers` 에 넣어 달라고 한다.
- 승인하면 미리보기에서 본 그대로만 올린다. 그사이 결재선이나 겹치는 문서가 바뀌면 미리보기를 다시 만든다.
- 같은 이름이 여러 부서에 있으면 설정에 `dept` 를 적는다. 좁혀지지 않으면 도구가 멈춘다.
- 기안 부서는 연결된 계정의 부서다.

## 올린 뒤

- 도구가 서버 문서를 다시 읽어 상태, 제목, 본문 칸, 결재선, 참조자를 대조한다. 다르면 실패로 알린다.
- 잘못 올렸으면 결재자가 처리하기 전에 `withdraw_document` 로 상신취소한다. 상신취소한 문서도 임시저장으로 남아 겹치는 문서로 잡힌다. 사람이 확인하면 `allowOverlap` 으로 새로 올리고, 남은 임시저장 문서는 사람에게 물어 지운다.
- 올린 출장은 플러그인에 기록된다. 지출결의가 영수증 없는 출장 경비(주유, 철도, 식대, 주차, 숙박)를 결제일로 이 기록과 잇는다.
