# 증명서 발급

`issue_certificate` 로 재직증명서와 경력증명서를 받는다. 신청 이력은 `certificate_history`.

## 네 단계 쓰기다

```
신청 저장 → 전자결재 상신 → 승인 → PDF 출력
```

전자결재가 승인되기 전에는 PDF 가 없다. 증명서를 "뽑는" 것은 조회가 아니라 결재 문서를 올리는 일이다. 도구는 미리보기를 만들고 멈추며, 사람이 승인해야 신청한다.

## 사람에게 받을 것

- **용도**: 신청 창의 선택지 가운데 하나다(대출용, 은행 제출용, 비자발급용, 경력증명용, 제안발표용, 제안서 제출용, 입찰 참가용, 기타, 조달청 제출용). 지어내지 않는다. 선택지에 없으면 미리보기가 고를 수 있는 값을 알려 준다.
- **제출처**: 자유 입력이다. 지어내지 않는다.
- **결재 경로**: 셀프승인인지 기본 결재선인지.

## 셀프승인

- 회사 설정 `certificate.selfApproval` 이 허락할 때만 쓴다.
- 결재선을 본인 단독(기안 나 → 결재 나)으로 바꿔 상신하고 본인이 바로 승인한다. 다른 사람에게 결재 알림이 가지 않고, 승인하는 즉시 결재가 끝나 PDF 가 나온다. 결재 기록과 결재승인번호는 남는다.
- 미리보기에서 이 점을 사람에게 분명히 알린다.
- 도구는 상신 전에 결재선에 다른 사람이 남아 있지 않은지 확인하고, 남아 있으면 멈춘다.

## 기본 결재선

양식의 기본 결재선으로 상신하면 결재선 사람에게 알림이 가고, 그 사람들이 승인해야 PDF 가 나온다. 승인된 뒤 같은 요청을 다시 하면 이어서 PDF 를 받는다.

## 이어서 처리

- 같은 종류, 용도, 제출처의 신청이 이미 있으면 새로 만들지 않고 남은 단계만 한다. 결재가 끝난 건은 유효일자 안이면 다시 출력한다.
- 셀프승인이 아닌데 같은 신청이 결재 중이면 멈춘다. 결재가 끝나면 다시 요청한다.
- 유효일자는 승인 뒤 한 달이다.

## PDF

- 주민번호 뒷자리(기본으로 가린다), 주소, 생년월일이 들어 있다. **본인에게 DM 으로만 보낸다.** 채널에 올리지 않고, 내용을 대화에 옮겨 적지 않는다.
- 플러그인은 PDF 를 디스크에 남기지 않는다.

## 다루지 않는 것

소득세 근로소득원천징수부는 소득년도 칸을 채우는 흐름을 확인하지 못해 이 도구가 다루지 않는다. 다우오피스 인사 화면에서 직접 신청한다.
