# 계정과 세션

## 계정 연결

- 계정은 사람마다 따로 연결한다. 봇이 DM 으로 [연결하기] 버튼을 보내고, 창(모달)에서 아이디와 비밀번호를 받는다. 대화창에 비밀번호를 적게 하지 않는다. 봇은 사용자의 DM 메시지를 지울 수 없다.
- 비밀번호는 봇이 암호화해 보관하고 모델에게 넘기지 않는다.
- 비밀번호가 틀리면 봇은 다시 시도하지 않고 다시 연결해 달라고 안내한다. 반복해서 틀리면 계정이 잠길 수 있다.

## 계정당 접속은 하나

- 같은 계정이 다른 곳(사람의 브라우저, 휴대전화 앱)에 접속해 있으면, 봇이 로그인할 때 "동시 접근 제한" 창이 뜨고 `기존 접속 종료` 를 눌러야 들어갈 수 있다. 누르면 다른 곳의 접속이 끊긴다.
- 봇은 사람이 허락했을 때만 그 버튼을 누른다. 연결할 때 "기존 접속을 끊어도 됩니다" 에 동의했거나, 그때마다 뜨는 [끊고 진행] 버튼을 눌렀을 때다.
- 허락이 없으면 봇은 물러나고 "다른 곳에서 접속 중입니다" 안내와 함께 [끊고 진행] [취소] 를 보낸다.

## 세션은 30분이면 끝난다

- 로그인한 지 30분쯤 지나면 활동과 관계없이 세션이 끝난다. 봇은 필요할 때 다시 로그인한다.
- 세션이 끝난 것과 다른 곳에서 로그인한 것은 구별할 수 없다. "다른 곳에서 로그인했다" 고 단정하지 않는다.
- 봇은 미리 다시 로그인하지 않는다. 로그인할 때마다 다른 곳의 접속을 끊을 수 있기 때문이다.

## 봇이 한 번에 하는 일

- 한 사람의 다우오피스 작업은 하나씩 차례로 처리한다.
- 여러 사람이 동시에 쓰면 잠시 기다릴 수 있다. 오래 기다리면 "잠시 뒤 다시 시도해 주세요" 라고 답한다.
