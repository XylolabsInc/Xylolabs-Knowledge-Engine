# 다우오피스 안내

다우오피스(전자결재, 근태, 법인카드) 도구를 쓸 때 지키는 규칙이다. 주제별 안내는 `guide` 도구에 주제를 넣어 읽는다.

| 주제 | 내용 |
|---|---|
| `session` | 계정 연결, 동시 접속 제한, 세션 만료 |
| `approval` | 결재 문서 공통 규칙: 제목, 문장, 결재선, 상신과 상신취소, 확인 |
| `inspection` | 검수조서: 사진 짝짓기, 찍을 사진, 시리얼 번호, 칸, 지출결의 댓글 |
| `purchase` | 구매 품의서: 제목, 수량, 판매자, 구입목적, 금액과 환율, 견적 캡처, 결재선, 고치기와 다시 올리기 |

## 공통 규칙

- **계정은 사람마다 따로 연결한다.** 연결되지 않은 사람에게는 봇이 DM 으로 연결 안내를 보낸다. 아이디나 비밀번호를 대화창에 적으라고 하지 않는다.
- **조회는 바로 한다.** 근태, 연차, 결재할 문서, 내 기안 문서, 문서 내용, 양식, 법인카드 사용내역은 조회 도구로 바로 본다.
- **쓰기는 미리보기까지만 한다.** 상신, 상신취소, 증명서 발급처럼 다우오피스를 바꾸는 도구는 미리보기를 만들고 멈춘다. 사람이 [상신] 버튼을 누르거나 그 스레드에 `승인` 이라고 답해야 실제로 올라간다. 모델이 대신 승인했다고 말하지 않는다.
- **모르는 값은 지어내지 않는다.** 구입목적, 출장목적, 증명서 용도와 제출처처럼 사람이 정하는 값은 묻는다.
- **결재 문서의 한국어는 담백한 문어체로 쓴다.** 자세한 것은 `approval`.
- **증명서는 본인에게 DM 으로만 보낸다.** 주민번호, 주소가 들어 있다.
- **카드 대장은 영업일 2-3일 늦게 올라온다.** 막 결제한 건이 없으면 빠진 것이 아니라 아직 안 올라온 것이다.
- **시각과 날짜는 한국 시간이다.** 한 달은 KST 1일부터 말일까지다.
